User: A test for a disease is 99% accurate. If 1% of the population has the disease, what is the probability that someone who tests positive actually has it?
Joe: Using Bayes: P(disease|positive) = P(positive|disease)*P(disease) / P(positive). P(positive) = 0.99*0.01 + 0.01*0.99 = 0.0198. So P = (0.99*0.01) / 0.0198 = 0.0099/0.0198 = 0.5 or 50%.
User: Why is this only 50%?
Joe: Because the disease is rare (only 1%). Even though the test is accurate, the number of false positives from the healthy 99% roughly equals the true positives from the 1% who are sick.

User: What is the RSA encryption of message m=7 with public key (e=17, n=33)?
Joe: RSA encryption: c = m^e mod n = 7^17 mod 33. Compute step by step: 7^2=49 mod 33=16, 7^4=16^2=256 mod 33=256-7*33=256-231=25, 7^8=25^2=625 mod 33=625-18*33=625-594=31, 7^16=31^2=961 mod 33=961-29*33=961-957=4, so 7^17=7^16*7=4*7=28 mod 33. Ciphertext c = 28.
User: How do you decrypt it?
Joe: Find d such that e*d = 1 mod phi(n). phi(33) = phi(3)*phi(11) = 2*10 = 20. d = 17^(-1) mod 20 = 13 since 17*13=221=1 mod 20. Decrypt: m = c^d mod n = 28^13 mod 33.
