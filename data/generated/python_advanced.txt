User: What is a list comprehension and how do you write one?
Joe: A list comprehension creates a new list from an iterable in a single expression: `[x*2 for x in range(10)]` produces a list of doubled numbers. It's more concise and usually faster than an equivalent for loop with append.

User: How do you filter items in a list comprehension?
Joe: Add an `if` clause at the end: `[x for x in range(20) if x % 3 == 0]` returns only multiples of three. You can chain conditions: `[x for x in range(20) if x % 2 == 0 if x % 3 == 0]`.

User: Can list comprehensions use an if-else expression?
Joe: Yes, but the if-else goes before the `for`: `[x if x % 2 == 0 else -x for x in range(10)]`. This is a ternary expression inside the comprehension, not a filter.

User: What is a dict comprehension?
Joe: Dict comprehensions build dictionaries inline: `{k: v**2 for k, v in d.items()}`. The syntax uses curly braces with a key-value pair before the `for` keyword.

User: How do you use a set comprehension?
Joe: Set comprehensions use curly braces without a colon: `{x**2 for x in range(-5, 6)}` produces a set of squares. Duplicates are automatically removed, just like in any set.

User: What is a generator expression and how does it differ from a list comprehension?
Joe: A generator expression uses parentheses instead of brackets: `(x**2 for x in range(10))`. It yields items one at a time lazily rather than building the entire list in memory.

User: Can you use a walrus operator inside a list comprehension?
Joe: Yes: `[(n := len(x)) for x in strings if n > 3]` captures the length in `n` while filtering. The walrus operator `:=` assigns and returns a value in a single expression.

User: What is a nested list comprehension?
Joe: Nested comprehensions flatten or build nested structures: `[[j for j in range(3)] for i in range(4)]` creates a 4x3 matrix. You can also flatten with `[x for row in matrix for x in row]`.

User: How do you write a nested dict comprehension?
Joe: `{'a': {i: i**2 for i in range(3)} for 'a' in 'bc'}` builds a nested dict. You can also build a flat dict from nested data: `{f'{k}{i}': v for k, d in items.items() for i, v in d.items()}`.

User: What does `*` do in list unpacking?
Joe: The star operator captures remaining elements: `first, *middle, last = [1,2,3,4,5]` assigns 1, [2,3,4], 5. It works in function arguments too: `func(*mylist)` unpacks as positional arguments.

User: How does the double star `**` unpack dictionaries?
Joe: `**` unpacks a dict into keyword arguments: `func(**{'x': 1, 'y': 2})` is the same as `func(x=1, y=2)`. Merging dicts: `merged = {**dict1, **dict2}` combines them.

User: What is a decorator in Python?
Joe: A decorator is a function that takes a function and returns a new function, typically wrapping it with extra behavior: `@timer def slow(): ...` is equivalent to `slow = timer(slow)`. They are syntactic sugar.

User: How do you write a simple function decorator?
Joe: Define a function that accepts a function and returns a wrapper: `def my_decorator(f): return lambda *a, **k: f(*a, **k)`. The wrapper runs before/after the original function.

User: Why is `functools.wraps` important in decorators?
Joe: `functools.wraps(f)` copies `__name__`, `__doc__`, and `__module__` from the original function to the wrapper. Without it, the decorated function's metadata is lost, breaking introspection and tools.

User: Can decorators accept arguments?
Joe: Yes, by nesting functions: `def repeat(n): def decorator(f): def wrapper(*a): for _ in range(n): f(*a); return wrapper; return decorator`. Then use `@repeat(3)`.

User: How do you stack multiple decorators?
Joe: Decorators are applied bottom-up: `@A @B def f(): ...` means `f = A(B(f))`. B wraps f first, then A wraps the result.

User: Can you decorate a class?
Joe: Yes, a decorator can return a modified or entirely new class. For example, `@dataclass` is itself a class decorator that auto-generates `__init__`, `__repr__`, and comparison methods.

User: What is a class decorator?
Joe: A class decorator is a function that receives a class and returns a modified class or replacement. It's used for automatic registration, validation, or adding methods.

User: How do you make a decorator that works on both functions and classes?
Joe: Check the type of the argument: `def decorate(obj): if isinstance(obj, type): return class_decorator(obj); return function_decorator(obj)`. Some libraries use this pattern.

User: What is `functools.lru_cache` and how do you use it?
Joe: `@lru_cache(maxsize=128)` memoizes function results based on arguments, caching the most recent calls. It dramatically speeds up recursive or repeated calls but requires hashable arguments.

User: How do you clear the cache of an lru_cache decorated function?
Joe: Call `func.cache_clear()` to remove all cached entries. You can also check `func.cache_info()` for hits, misses, and current cache size.

User: What is `functools.singledispatch`?
Joe: `@singledispatch` allows a function to have different implementations based on the type of its first argument. You register new types with `func.register(int)(int_handler)`.

User: What does `functools.reduce` do?
Joe: `reduce(function, iterable)` applies a function of two arguments cumulatively to an iterable, reducing it to a single value: `reduce(lambda a,b: a+b, [1,2,3])` returns 6.

User: What is `functools.partial`?
Joe: `partial(func, arg1)` creates a new callable with some arguments pre-filled: `int2 = partial(int, base=2)` creates a binary parser. It's simpler than writing a full lambda wrapper.

User: What is `functools.total_ordering`?
Joe: A class decorator that fills in comparison methods from `__eq__` and one of `__lt__`, `__le__`, `__gt__`, or `__ge__`. You define two, it generates the other four.

User: How do generators work with `yield`?
Joe: A generator function pauses at each `yield` and resumes where it left off on the next call to `next()`. The local state is preserved between yields.

User: What is `yield from`?
Joe: `yield from iterable` is shorthand for looping over an iterable and yielding each item. It's especially useful for delegating to sub-generators: `yield from sub_gen()`.

User: How do you send values into a generator?
Joe: Use `gen.send(value)` to resume the generator and inject a value as the result of the `yield` expression: `val = yield something`. The first call must be `next(gen)` or `gen.send(None)`.

User: What does `generator.throw()` do?
Joe: `gen.throw(exc_type)` raises an exception inside the generator at the point of the last `yield`. The generator can catch it with try/except or let it propagate.

User: What is a generator pipeline?
Joe: A generator pipeline chains multiple generators where each one processes the output of the previous one using `yield from`. It's a lazy, memory-efficient way to process data streams.

User: How do you convert a generator to a list?
Joe: Call `list(my_generator)` to consume all values and store them in a list. Be careful with infinite generators as this will never terminate.

User: What is the difference between an iterator and a generator?
Joe: Every generator is an iterator, but not every iterator is a generator. Generators are created with yield syntax or generator expressions, while iterators implement `__iter__` and `__next__` manually.

User: How do you create an iterator class?
Joe: Implement `__iter__` returning `self` and `__next__` returning the next value or raising `StopIteration`. For example: `class Count: def __init__(self, n): self.n = self.i = 0; def __iter__(self): return self; def __next__(self): if self.i >= self.n: raise StopIteration; self.i += 1; return self.i`.

User: What is a context manager?
Joe: A context manager manages setup and teardown around a block of code using the `with` statement. It implements `__enter__` (setup) and `__exit__` (cleanup) methods.

User: How do you write a custom context manager class?
Joe: Define `__enter__(self)` and `__exit__(self, exc_type, exc_val, exc_tb)`: `__enter__` returns the resource, `__exit__` handles cleanup and optionally suppresses exceptions by returning True.

User: What does `__exit__` receive when an exception occurs?
Joe: It receives the exception type, value, and traceback. If no exception occurred, all three are None. Returning True from `__exit__` suppresses the exception.

User: How do you create a context manager with `contextlib.contextmanager`?
Joe: Decorate a generator with `@contextmanager`, yield the resource, and put cleanup code after the yield in a try/finally block. The generator should yield exactly once.

User: What is `contextlib.closing`?
Joe: `closing(obj)` calls `obj.close()` on exit regardless of whether an exception occurred. It's a shortcut for objects that have a `close()` method but don't implement the full context manager protocol.

User: How do you create an async context manager?
Joe: Implement `__aenter__` and `__aexit__` that are async methods, or use `@asynccontextmanager` from contextlib. Usage requires `async with` syntax.

User: What is `contextlib.suppress`?
Joe: `contextlib.suppress(FileNotFoundError)` is a context manager that silences specific exceptions. Code inside the block runs normally, but the specified exceptions are swallowed.

User: How do you chain context managers together?
Joe: Use `with` with commas: `with open('a') as fa, open('b') as fb: ...`. Alternatively, use `contextlib.ExitStack` for a dynamic number of context managers.

User: What is `contextlib.ExitStack`?
Joe: `ExitStack` manages a dynamic collection of context managers. You `enter_context()` to add them, and they're all cleaned up when the ExitStack exits, in LIFO order.

User: How do type hints work in Python?
Joe: Type hints annotate function signatures and variables: `def greet(name: str) -> str:`. They don't enforce types at runtime but help with tooling like mypy and IDE autocompletion.

User: What is `Optional` in typing?
Joe: `Optional[str]` is equivalent to `Union[str, None]` and means the value can be a string or None. Always use it instead of just `str` when None is a valid value.

User: What is the difference between `Union` and `|` for type hints?
Joe: `Union[str, int]` and `str | int` (Python 3.10+) mean the same thing. The pipe syntax is shorter and more readable, but `Union` works in older Python versions.

User: How do you hint the return type of a function that returns nothing?
Joe: Use `-> None` as the return type annotation. Functions without a return type annotation implicitly have `None` return type, but being explicit is better for clarity.

User: What are `List`, `Dict`, `Tuple`, and `Set` in typing?
Joe: These are generic aliases from the `typing` module for built-in containers. In Python 3.9+, you can use lowercase `list[int]`, `dict[str, int]` directly without importing from typing.

User: What is `TypeVar` and when do you use it?
Joe: `TypeVar('T')` creates a type variable for generic functions or classes. It lets you express that a function returns the same type as its input: `def identity(x: T) -> T: return x`.

User: What are Generic classes?
Joe: Generic classes use `TypeVar` to parameterize types: `class Stack(Generic[T])`. This allows `Stack[int]` or `Stack[str]` to enforce type consistency throughout usage.

User: What is `Protocol` for structural subtyping?
Joe: `Protocol` defines an interface by method signatures without inheritance: `class Drawable(Protocol): def draw(self) -> None: ...`. Any object with a `draw` method satisfies it, even without subclassing.

User: How do you define a `Literal` type?
Joe: `Literal['a', 'b', 'c']` restricts a variable to exact values. In Python 3.8+, import from `typing`, and use it for parameters that should only accept specific strings or numbers.

User: What is `Annotated` in typing?
Joe: `Annotated[int, "positive"]` adds metadata to a type hint. Libraries like FastAPI and Pydantic use it to attach validation rules, descriptions, or constraints to types.

User: What is `Final` in typing?
Joe: `Final[int] = 42` declares a constant that should not be reassigned. It signals to type checkers that the variable is a constant.

User: What is `TypeAlias`?
Joe: `TypeAlias` signals that an assignment is a type alias: `Matrix: TypeAlias = list[list[float]]`. It makes it clear the name is a type, not a runtime value.

User: How do you type hint a callable?
Joe: Use `Callable[[arg_types], return_type]`: `Callable[[int, str], bool]` means a function taking int and str returning bool. Import it from `typing` or `collections.abc`.

User: What is the walrus operator `:=`?
Joe: The walrus operator assigns a value to a variable as part of an expression: `if (n := len(data)) > 10: print(n)`. It avoids redundant computations and keeps code concise.

User: Give a practical use of the walrus operator in a while loop.
Joe: `while (line := f.readline()): process(line)` reads lines until EOF. The assignment is part of the condition, so no separate initialization and update lines are needed.

User: How is the walrus operator useful in list comprehensions?
Joe: `[y := f(x) for x in range(10) if y > 5]` avoids computing `f(x)` twice. The value is computed once and reused in both the filter and the output expression.

User: What is a match/case statement in Python 3.10+?
Joe: `match`/`case` is structural pattern matching: `match value: case 1: ... case str() as s: ...` matches against patterns including literals, types, and structured data.

User: Can match/case use wildcard patterns?
Joe: Yes, `_` is the wildcard that matches anything: `match x: case 0: ... case _: ...`. It's like a default case and should be the last pattern.

User: How do you match against sequences in match/case?
Joe: Use unpacking: `case [first, *rest]:` matches a sequence and captures the first element and the rest. Works with lists, tuples, and other sequences.

User: Can match/case use guard clauses?
Joe: Yes, add an `if` after the pattern: `case x if x > 0:` matches positive numbers. The guard is an additional condition that must be true for the case to match.

User: How do you match against class attributes?
Joe: Use class patterns: `case Point(x=0, y=y):` matches a Point where x is 0 and captures y. You can omit attribute names if the position is unambiguous.

User: What is `raise from` in exception chaining?
Joe: `raise ValueError("bad") from original_exc` links the new exception to the original one. The traceback shows both exceptions, preserving the full cause of the error.

User: How do you create a custom exception class?
Joe: Inherit from `Exception`: `class MyError(Exception): pass`. You can add custom attributes like error codes or details, and override `__str__` for custom messages.

User: What are exception groups in Python 3.11+?
Joe: `ExceptionGroup("msg", [exc1, exc2])` bundles multiple exceptions into one. Use `except*` to catch specific sub-groups: `except* ValueError as eg: handle(eg.exceptions)`.

User: How does `except*` work?
Joe: `except* TypeError` catches all TypeError exceptions within an ExceptionGroup. Multiple `except*` blocks can each handle different exception types from the same group.

User: What is the `assert` statement?
Joe: `assert condition, "message"` raises `AssertionError` if the condition is false. It's used for debugging and should not be used for validating user input since assertions can be disabled with `-O`.

User: How do you use the `re` module for pattern matching?
Joe: `re.search(r'\d+', text)` finds the first occurrence of a pattern. `re.match` checks from the start, `re.findall` returns all matches as a list, and `re.sub` replaces matches.

User: What are groups in regular expressions?
Joe: Parentheses create groups: `re.match(r'(\d+)-(\d+)', '123-456')`. Use `.group(1)` to get the first captured group, `.groups()` to get all as a tuple.

User: What are named groups in regex?
Joe: `(?P<name>\d+)` creates a named group. Access it with `match.group('name')`. Named groups make patterns self-documenting and easier to maintain.

User: What is lookahead in regex?
Joe: `(?=...)` is a lookahead that asserts what follows without consuming: `r'\d+(?=px)'` matches digits followed by "px" but doesn't include "px" in the match.

User: What is lookbehind in regex?
Joe: `(?<=...)` is a lookbehind that asserts what precedes: `r'(?<=\$)\d+'` matches digits after a dollar sign without including the dollar sign. The pattern must be fixed-width.

User: How do you compile a regex pattern?
Joe: `pattern = re.compile(r'\d+')` compiles the regex for reuse. Compiled patterns are faster for repeated use and support methods like `pattern.search(text)` directly.

User: What are non-capturing groups?
Joe: `(?:...)` groups without capturing: `re.findall(r'(?:Mr|Ms)\. \w+', text)`. They're useful for applying quantifiers or alternation without creating a backreference.

User: How do you use the `DOTALL` flag?
Joe: `re.search(r'.+', text, re.DOTALL)` makes `.` match newlines too. Without it, `.` matches any character except newline.

User: What does `re.VERBOSE` do?
Joe: `re.VERBOSE` allows you to write regex patterns with comments and whitespace for readability. Regular spaces are ignored unless escaped or inside a character class.

User: How do you format strings with f-strings?
Joe: F-strings embed expressions: `f"Hello, {name}!"` or `f"Result: {x + y:.2f}"` for formatting. They evaluate expressions at runtime and are the most readable string formatting method.

User: What formatting options are available in f-strings?
Joe: `:.2f` for 2 decimal places, `:,.0f` for comma-separated thousands, `:>10` for right-align in 10 chars, `:05d` for zero-padded integers, `:^10` for center-align.

User: Can f-strings contain complex expressions?
Joe: Yes, including function calls: `f"{func(x):.2f}"`. However, backslashes and comments are not allowed inside f-string expressions in Python 3.11 and earlier.

User: How does the `.format()` method work?
Joe: `"Hello, {}!".format(name)` replaces `{}` with positional arguments. You can use indices `{0}`, named arguments `{name}`, and format specs `{:.2f}`.

User: What is the `%` string formatting operator?
Joe: `"Hello, %s! You are %d." % (name, age)` is the old-style formatting. `%s` for strings, `%d` for integers, `%f` for floats. It's considered legacy but still widely used.

User: What is `string.Template`?
Joe: `Template("Hello, $name!").substitute(name="World")` provides safe string substitution. It's useful when the template comes from untrusted input since it avoids code injection.

User: How do you handle thousands separator in Python formatting?
Joe: Use `f"{1234567:,.2f}"` which outputs `1,234,567.00`. The comma flag adds thousands separators automatically.

User: What is `os.path` used for?
Joe: `os.path.join`, `os.path.exists`, `os.path.basename`, `os.path.dirname` handle file system paths in a platform-independent way. Always use `os.path` or `pathlib` instead of string concatenation.

User: What is `pathlib.Path`?
Joe: `Path("folder/file.txt")` is an object-oriented path representation. Methods like `.exists()`, `.read_text()`, `.stem`, `.suffix`, and the `/` operator for joining make it more intuitive than `os.path`.

User: How do you read a file with `pathlib`?
Joe: `Path("file.txt").read_text(encoding="utf-8")` reads the entire file as a string. For binary: `Path("file.bin").read_bytes()`. Writing works similarly with `write_text()`.

User: How do you read a file line by line efficiently?
Joe: `with open("file.txt") as f: for line in f: process(line)` is memory-efficient as it reads one line at a time. The file object is an iterator that loads chunks as needed.

User: What is binary mode in file I/O?
Joe: `open("file.bin", "rb")` opens a file for reading raw bytes instead of text. Use binary mode for images, pickled data, or any non-text content. Writing binary uses "wb".

User: How do you handle encoding when opening files?
Joe: `open("file.txt", encoding="utf-8")` specifies the character encoding. Always specify encoding explicitly rather than relying on the platform default to avoid UnicodeErrors.

User: What is `tempfile` module for?
Joe: `tempfile.NamedTemporaryFile()` creates a temporary file that's automatically cleaned up. `tempfile.mkdtemp()` creates a temporary directory. Both are useful for intermediate data.

User: How do you copy files and directories in Python?
Joe: `shutil.copy2(src, dst)` copies a file preserving metadata. `shutil.copytree(src, dst)` copies an entire directory tree. `shutil.rmtree(path)` deletes a directory tree.

User: What is `defaultdict` and when do you use it?
Joe: `defaultdict(list)` creates a dictionary where missing keys automatically get an empty list. It eliminates the need for `setdefault` or checking if a key exists before appending.

User: How do you use `collections.Counter`?
Joe: `Counter("abracadabra")` counts occurrences: returns `{'a': 5, 'b': 2, 'r': 2, ...}`. Methods like `.most_common(3)` return the top three elements.

User: What is `collections.deque`?
Joe: `deque([1, 2, 3])` is a double-ended queue with O(1) appends and pops from both ends. `deque(maxlen=1000)` automatically discards old items when full.

User: What is `namedtuple`?
Joe: `Point = namedtuple('Point', ['x', 'y'])` creates a tuple subclass with named fields: `p = Point(1, 2); p.x` returns 1. It's lightweight and immutable.

User: How do you use `collections.OrderedDict`?
Joe: `OrderedDict()` preserves insertion order of keys. In Python 3.7+ regular dicts also preserve order, but `OrderedDict` adds `.move_to_end()` and order-sensitive equality comparison.

User: What does `itertools.chain` do?
Joe: `chain([1,2], [3,4])` concatenates iterables into a single stream: 1, 2, 3, 4. It's lazy and avoids creating intermediate lists.

User: How does `itertools.product` work?
Joe: `product([0,1], repeat=3)` generates all combinations with repetition: (0,0,0), (0,0,1), ..., (1,1,1). Like nested for loops in a single call.

User: What do `itertools.combinations` and `itertools.permutations` do?
Joe: `combinations([1,2,3], 2)` gives (1,2), (1,3), (2,3) — order doesn't matter. `permutations([1,2,3], 2)` also gives (2,1) and (3,1) — order matters.

User: How does `itertools.groupby` work?
Joe: `groupby(sorted(data, key=key_func), key_func)` groups consecutive elements with the same key. The input must be sorted by the grouping key first, or you'll get unexpected groups.

User: What is `itertools.starmap`?
Joe: `starmap(pow, [(2,3), (4,5)])` applies a function to tuples as arguments, equivalent to `[pow(2,3), pow(4,5)]`. It unpacks each item as positional arguments.

User: What does `itertools.accumulate` do?
Joe: `accumulate([1,2,3,4])` returns a running total: 1, 3, 6, 10. You can pass a custom function: `accumulate([1,2,3], operator.mul)` gives 1, 2, 6.

User: What is `dataclasses.dataclass`?
Joe: `@dataclass` auto-generates `__init__`, `__repr__`, and `__eq__` from class annotations: `@dataclass class Point: x: int; y: int`. It reduces boilerplate for data-holding classes.

User: How do you make a frozen dataclass?
Joe: `@dataclass(frozen=True)` makes instances immutable by implementing `__hash__` and raising an error on attribute assignment. Frozen instances can be used as dictionary keys.

User: What is `field` in dataclasses?
Joe: `field(default_factory=list, metadata={"desc": "items"})` customizes individual fields. `default_factory` provides mutable defaults safely, and `metadata` stores arbitrary info.

User: How do you add `__post_init__` to a dataclass?
Joe: Define `__post_init__(self)` in your dataclass to run code after the auto-generated `__init__`. It's used for validation, computed fields, or derived values.

User: How do you inherit from a dataclass?
Joe: Subclass normally: `class Point3D(Point): z: int`. Child fields are appended after parent fields. Use `@dataclass(order=True)` on both parent and child for comparison support.

User: What is the `__slots__` attribute?
Joe: `__slots__ = ['x', 'y']` restricts instance attributes to a fixed set, reducing memory usage and improving attribute access speed. You can't add new attributes not in `__slots__`.

User: How do `property`, `classmethod`, and `staticmethod` work?
Joe: `@property` creates a getter method accessed like an attribute. `@classmethod` receives the class as the first argument. `@staticmethod` receives neither self nor cls.

User: What is `sys.getsizeof` used for?
Joe: `sys.getsizeof(obj)` returns the memory size of a single object in bytes. It doesn't include the size of contained objects — use `pympler.asizeof` for recursive size measurement.

User: How do you use `timeit` for benchmarking?
Joe: `timeit.timeit("sum(range(100))", number=10000)` times code execution. Use the `timeit` module rather than manual timing to avoid common measurement pitfalls.

User: What is `__init_subclass__` used for?
Joe: `__init_subclass__(cls, **kwargs)` is called when a class is subclassed. It's used for automatic registration, validation, or adding behavior to subclasses without metaclasses.

User: What is a descriptor?
Joe: A descriptor is a class with `__get__`, `__set__`, or `__delete__` methods. When accessed as a class attribute, Python invokes the descriptor protocol. `property`, `classmethod`, and `staticmethod` are descriptors.

User: How do you implement a custom descriptor?
Joe: Define `__get__(self, obj, objtype)` to return the value. If `obj` is None, return the descriptor itself (class-level access). For data descriptors, also implement `__set__`.

User: What is a metaclass?
Joe: A metaclass is the class of a class. `type` is the default metaclass. Custom metaclasses override `__new__` or `__init__` to modify class creation, like adding methods or enforcing interfaces.

User: When should you use a metaclass?
Joe: Rarely — most metaclass use cases can be handled with class decorators. Use metaclasses when you need to modify class behavior at creation time and decorators aren't sufficient, such as for framework APIs.

User: How does `__set_name__` work?
Joe: `__set_name__(self, owner, name)` is called automatically when a descriptor is assigned to a class attribute. It receives the owning class and the attribute name, useful for self-naming descriptors.

User: How do you use `logging.basicConfig`?
Joe: `logging.basicConfig(level=logging.INFO, format='%(asctime)s %(message)s')` configures the root logger with a level and format. Call it once at startup before creating any loggers.

User: What are the logging levels in order?
Joe: DEBUG, INFO, WARNING, ERROR, CRITICAL from least to most severe. `logging.warning("low disk")` logs at WARNING level. Use `logger = logging.getLogger(__name__)` for per-module loggers.

User: How do you create a custom log formatter?
Joe: Subclass `logging.Formatter` and override `format()`, or pass a format string with fields like `%(name)s`, `%(levelname)s`, `%(lineno)d` to the Formatter constructor.

User: What is a logging Handler?
Joe: Handlers direct log output to different destinations: `StreamHandler` for console, `FileHandler` for files, `RotatingFileHandler` for log rotation. Attach them with `logger.addHandler(handler)`.

User: How does `argparse` parse command-line arguments?
Joe: `parser = argparse.ArgumentParser(); parser.add_argument("--name", required=True); args = parser.parse_args()`. Access values via `args.name`. Supports positional and optional arguments.

User: How do you add subcommands with argparse?
Joe: Use `subparsers = parser.add_subparsers()`. Create each subcommand: `sp = subparsers.add_parser("build"); sp.add_argument("target")`. Each subcommand gets its own arguments.

User: What is `argparse` type conversion?
Joe: `parser.add_argument("--port", type=int)` automatically converts the string argument to an integer. You can pass any callable: `type=Path` or `type=lambda x: x.split(",")`.

User: How do you use virtual environments?
Joe: `python3 -m venv myenv` creates a virtual environment. Activate it: `source myenv/bin/activate`. Install packages with `pip install package`. Deactivate with `deactivate`.

User: What is `pyproject.toml`?
Joe: `pyproject.toml` is the modern Python project configuration file replacing `setup.py`. It specifies build system, dependencies, and tool configs like `[tool.pytest]` and `[tool.mypy]`.

User: What is the difference between venv and virtualenv?
Joe: `venv` is in the standard library and creates lightweight environments. `virtualenv` is a third-party tool that's faster, supports Python 2, and can create environments with older Pythons.

User: How do you use `pdb` for debugging?
Joe: Run `python3 -m pdb script.py` to start in debugger mode. Use `b` to set breakpoints, `n` for next line, `s` for step into, `c` to continue, `p expr` to print, and `q` to quit.

User: What does `breakpoint()` do?
Joe: `breakpoint()` is a built-in that drops into `pdb` at that line. In Python 3.7+, it's equivalent to `import pdb; pdb.set_trace()`. Set `PYTHONBREAKPOINT=0` to disable all breakpoints.

User: How do you use `traceback` module?
Joe: `traceback.print_exc()` prints the current exception's traceback. `traceback.format_exception(exc)` returns the traceback as a list of strings for custom handling.

User: What is `faulthandler`?
Joe: `import faulthandler; faulthandler.enable()` dumps tracebacks of all threads on a fatal error or segfault. It helps debug C-level crashes that don't produce Python tracebacks.

User: How do you use `threading` in Python?
Joe: `threading.Thread(target=func, args=(arg1,)).start()` creates and runs a thread. Use `thread.join()` to wait for completion. Note that the GIL limits true parallelism for CPU-bound tasks.

User: What is `multiprocessing`?
Joe: `multiprocessing.Process(target=func)` spawns a separate process with its own Python interpreter. It bypasses the GIL for true parallelism but has higher overhead than threads.

User: How does `concurrent.futures.ThreadPoolExecutor` work?
Joe: `with ThreadPoolExecutor(max_workers=4) as pool: futures = [pool.submit(work, item) for item in data]`. Use `as_completed(futures)` or `future.result()` to get results.

User: What is `ProcessPoolExecutor`?
Joe: `ProcessPoolExecutor` works like `ThreadPoolExecutor` but uses processes instead of threads, bypassing the GIL. Ideal for CPU-bound tasks that can be parallelized.

User: How does `asyncio` work?
Joe: `async def fetch(): await aiohttp.get(url)` defines a coroutine. Run with `asyncio.run(main())`. `await` suspends execution until the awaited coroutine completes, allowing other tasks to run.

User: What is an async event loop?
Joe: `asyncio.run(main())` creates an event loop, runs the coroutine, and closes the loop. The loop schedules and runs coroutines cooperatively, switching between them at `await` points.

User: How do you run multiple coroutines concurrently?
Joe: `await asyncio.gather(coroutine1(), coroutine2())` runs them concurrently and returns results in order. `asyncio.create_task(coro)` schedules a coroutine without blocking.

User: What are async generators?
Joe: `async def gen(): yield await fetch_data()` is an async generator. Iterate with `async for item in gen()`. Useful for streaming data from async sources.

User: What are async context managers?
Joe: `async with aiohttp.ClientSession() as session:` uses `__aenter__` and `__aexit__`. They're necessary when setup or teardown involves async operations.

User: How do you use `json.loads` and `json.dumps`?
Joe: `json.loads('{"a": 1}')` parses a JSON string into a Python dict. `json.dumps({"a": 1})` serializes a Python object to a JSON string. Add `indent=2` for pretty printing.

User: How do you write a custom JSON encoder?
Joe: Subclass `json.JSONEncoder` and override `default(self, obj)`: `def default(self, obj): if isinstance(obj, datetime): return obj.isoformat(); return super().default(obj)`.

User: What are JSON Lines?
Joe: JSON Lines is one JSON object per line. Read with: `for line in f: data.append(json.loads(line))`. Write with: `f.write(json.dumps(obj) + '\n')`. It's useful for streaming large datasets.

User: How do you handle `datetime` objects?
Joe: `datetime.now()` gives the current time. `dt.strftime("%Y-%m-%d %H:%M")` formats to string. `datetime.strptime(s, "%Y-%m-%d")` parses from string.

User: What is `timedelta`?
Joe: `timedelta(days=7)` represents a duration. Add it to a datetime: `datetime.now() + timedelta(hours=1)`. Subtract two datetimes to get a timedelta: `dt2 - dt1`.

User: How do you handle timezones in datetime?
Joe: `from datetime import timezone; dt = datetime.now(timezone.utc)` gets UTC time. Use `dt.astimezone(tz)` to convert. The `pytz` or `dateutil` library provides named timezones.

User: What is `dateutil.parser`?
Joe: `dateutil.parser.parse("March 14, 2026")` parses various date string formats automatically. It handles many formats that `strptime` can't without explicit format strings.

User: What does `os.environ` do?
Joe: `os.environ` is a dict of environment variables. `os.environ.get("HOME")` safely retrieves one. Set with `os.environ["MY_VAR"] = "value"` or `os.environ.update({"A": "1"})`.

User: What is `sys.argv`?
Joe: `sys.argv` is a list of command-line arguments. `sys.argv[0]` is the script name, `sys.argv[1:]` are the arguments. Use `argparse` for anything beyond simple scripts.

User: What is `sys.path`?
Joe: `sys.path` is the list of directories Python searches for modules. `sys.path.insert(0, '/my/libs')` adds a directory to the front. It's initialized from `PYTHONPATH` and installed packages.

User: How do you use `platform` module?
Joe: `platform.python_version()` returns the Python version string. `platform.system()` returns 'Linux', 'Darwin', or 'Windows'. Useful for platform-specific behavior.

User: How do you profile Python code?
Joe: `cProfile.run("my_func()")` shows function call statistics. `python3 -m cProfile script.py` profiles the entire script. Use `snakeviz` to visualize the results.

User: What is `memory_profiler`?
Joe: `@profile` decorator from `memory_profiler` tracks memory usage line by line. Run with `python3 -m memory_profiler script.py` to see memory consumption at each line.

User: How do you use `functools.reduce` to flatten a nested list?
Joe: `reduce(lambda a, b: a + b, nested_list)` flattens one level. For deep flattening: `def flatten(lst): return [x for item in lst for x in (flatten(item) if isinstance(item, list) else [x])]`.

User: What is `inspect` module used for?
Joe: `inspect.getsource(func)` retrieves source code. `inspect.signature(func)` gets function parameters. `inspect.stack()` shows the call stack. Useful for debugging and metaprogramming.

User: How do you create a singleton class in Python?
Joe: Override `__new__`: `def __new__(cls): if not hasattr(cls, '_inst'): cls._inst = super().__new__(cls); return cls._inst`. Alternatively, use a module-level variable.

User: What is `__slots__` and how does it save memory?
Joe: `__slots__ = ('x', 'y')` prevents creating a per-instance `__dict__`, using a fixed-size array instead. This saves memory per instance, which adds up with millions of objects.

User: How do you use `enum.Enum`?
Joe: `class Color(Enum): RED = 1; GREEN = 2; BLUE = 3`. Access with `Color.RED`. Use `.value` for the underlying value and `.name` for the string name.

User: What is `enum.IntEnum`?
Joe: `IntEnum` inherits from int, so members can be used directly in comparisons and arithmetic: `if color == Color.RED: ...` works because `Color.RED == 1` is True.

User: How do you use `collections.abc` for abstract base classes?
Joe: `from collections.abc import Iterable, Mapping`. Use `isinstance(obj, Iterable)` to check if an object is iterable. These are more reliable than checking for specific types.

User: What is the `abc.ABC` class?
Joe: Inherit from `ABC` and use `@abstractmethod` to define required methods: `class Base(ABC): @abstractmethod def compute(self): ...`. You can't instantiate a class with unimplemented abstract methods.

User: How do you use `typing.runtime_checkable`?
Joe: `@runtime_checkable class MyProtocol(Protocol): ...` makes `isinstance(obj, MyProtocol)` work at runtime. Without it, Protocol only works for static type checking.

User: What is `asyncio.Queue`?
Joe: `asyncio.Queue()` is an async-safe FIFO queue. `await queue.put(item)` adds items, `await queue.get()` retrieves them. It's used to coordinate producer and consumer coroutines.

User: How do you limit concurrency with `asyncio.Semaphore`?
Joe: `sem = asyncio.Semaphore(10)` limits to 10 concurrent operations. Use `async with sem:` before awaiting the operation. This prevents overwhelming external services.

User: What is `numpy` and its basic data structure?
Joe: `numpy.array([1,2,3])` creates an ndarray, a homogeneous N-dimensional array. It supports vectorized operations: `arr * 2` multiplies all elements without explicit loops.

User: How does numpy broadcasting work?
Joe: Broadcasting automatically aligns arrays of different shapes for operations: `np.array([1,2,3]) + 10` adds 10 to each element. Shapes are aligned from the right, with size-1 dimensions expanded.

User: How do you index numpy arrays?
Joe: `arr[0]` gets the first element, `arr[1:4]` slices, `arr[arr > 5]` boolean indexes, `arr[[0,2,5]]` fancy indexes. Multi-dimensional: `arr[0, :]` gets the first row.

User: What are numpy dtypes?
Joe: `np.array([1,2,3], dtype=np.float32)` specifies the data type. Common dtypes: `int32`, `float64`, `complex128`, `bool_`. Using smaller dtypes like `float16` saves memory.

User: What is `argparse`'s `nargs` parameter?
Joe: `nargs='+'` requires one or more arguments, `nargs='*'` accepts zero or more, `nargs=3` requires exactly three. `nargs='?'` makes the argument optional with an optional default.

User: How do you handle signals in Python?
Joe: `signal.signal(signal.SIGINT, handler)` registers a handler for the SIGINT signal. The handler receives the signal number and frame. Return to the interrupted code.

User: What is `hashlib` for?
Joe: `hashlib.sha256(b"data").hexdigest()` computes a SHA-256 hash. Used for password hashing (with salt), data integrity checks, and creating unique identifiers.

User: How do you use `pathlib` to walk directories?
Joe: `Path("dir").rglob("*.py")` recursively finds all Python files. `Path("dir").iterdir()` lists immediate children. `Path("dir").glob("*")` matches non-recursively.

User: What is `shutil.make_archive`?
Joe: `shutil.make_archive("backup", "zip", "source_dir")` creates a zip archive of a directory. Supports formats: zip, tar, gztar, bztar, xztar.

User: How do you use `decimal.Decimal` for precise arithmetic?
Joe: `Decimal("0.1") + Decimal("0.2")` gives exactly `0.3`, unlike float. Always construct from strings, not floats: `Decimal(0.1)` already has float imprecision.

User: What is `fractions.Fraction`?
Joe: `Fraction(1, 3)` represents one-third exactly. Supports arithmetic: `Fraction(1, 3) + Fraction(1, 6)` gives `Fraction(1, 2)`. Useful when floating-point precision isn't acceptable.

User: How do you use `itertools.zip_longest`?
Joe: `zip_longest([1,2], [3], fillvalue=0)` gives (1,3), (2,0). It pads the shorter iterable with the fill value instead of stopping at the shortest one like `zip`.

User: What is `itertools.islice`?
Joe: `islice(iterable, 10, 20)` slices an iterator like a list slice. It works on any iterable, not just sequences, and avoids materializing the whole thing in memory.

User: How do you use `heapq` module?
Joe: `heapq.heappush(heap, item)` and `heapq.heappop(heap)` maintain a min-heap. `heapq.nsmallest(3, data)` efficiently finds the 3 smallest elements.

User: What is `bisect` module?
Joe: `bisect.bisect_left(sorted_list, x)` finds the insertion point for `x` in sorted order. `bisect.insort(sorted_list, x)` inserts while maintaining sorted order. Both are O(log n).

User: How do you use `collections.ChainMap`?
Joe: `ChainMap(dict1, dict2)` treats multiple dicts as one, with the first dict taking priority. Useful for merging configuration layers: defaults, config file, environment variables.

User: What is `typing.NamedTuple`?
Joe: `Point = NamedTuple('Point', [('x', int), ('y', int)])` creates a typed namedtuple. It's equivalent to defining a class but with tuple behavior and type annotations.

User: How do you use `dataclasses.asdict`?
Joe: `dataclasses.asdict(instance)` recursively converts a dataclass instance to a dictionary. Useful for JSON serialization or passing dataclass fields as keyword arguments.

User: What is `__class_getitem__`?
Joe: `__class_getitem__` allows a class to be parameterized with brackets: `class Stack: def __class_getitem__(cls, item): return cls`. This enables `Stack[int]` syntax.

User: How do you use `typing.TYPE_CHECKING`?
Joe: `if TYPE_CHECKING:` imports only during static analysis. It's used to import types for annotations without creating circular imports or runtime overhead.

User: What is `typing.overload`?
Joe: `@overload` declares multiple type signatures for a function. The actual implementation is untyped. It helps type checkers understand functions with different return types based on arguments.

User: How do you use `typing.Annotated` for validation?
Joe: `Annotated[int, Field(ge=0)]` with Pydantic or FastAPI adds constraints. The annotation metadata is processed by the framework at runtime for validation.

User: What is `__dataclass_fields__`?
Joe: `cls.__dataclass_fields__` is a dict of field name to Field objects. It's automatically generated by `@dataclass` and useful for introspection of dataclass structure.

User: How do you handle circular imports?
Joe: Use `TYPE_CHECKING` for import-time hints and lazy imports inside functions: `def func(): from module import thing`. Avoid module-level circular imports.

User: What is `importlib` used for?
Joe: `importlib.import_module("os.path")` dynamically imports a module by string name. `importlib.reload(module)` re-imports a module after changes. Both are useful for plugin systems.

User: How do you create a Python package?
Joe: Create a directory with `__init__.py` (can be empty). Add modules as `.py` files. Use `pyproject.toml` for metadata. The directory name becomes the package name.

User: What is `__all__` in a module?
Joe: `__all__ = ['func1', 'func2']` defines what `from module import *` imports. It's a list of strings naming public API objects. It doesn't affect explicit imports.

User: How do you use `functools.lru_cache` with class methods?
Joe: Apply it to the method, but cache is shared across instances. To cache per-instance, use a custom wrapper. Alternatively, cache expensive computations in instance attributes.

User: What is `typing.get_type_hints`?
Joe: `get_type_hints(func)` returns the resolved type hints as a dict, evaluating forward references. It's useful for introspecting annotations in a portable way.

User: How do you use `__set_name__` for self-naming descriptors?
Joe: Define `__set_name__(self, owner, name)` in your descriptor class. Python calls it automatically when the class is created: `class Foo: attr = MyDescriptor()`. The descriptor now knows it's named "attr".

User: What is `operator` module?
Joe: `operator.add(1, 2)` is the function form of `+`. `operator.attrgetter('name')` creates a callable that gets the name attribute. Useful as arguments to `map`, `sorted`, `reduce`.

User: How do you use `map` and `filter`?
Joe: `map(int, ["1","2","3"])` applies a function to each item. `filter(lambda x: x > 0, nums)` keeps items where the function returns True. Both return iterators.

User: What is `zip` and how do you use `strict` mode?
Joe: `zip([1,2], [3,4])` pairs elements: (1,3), (2,4). `zip(a, b, strict=True)` raises `ValueError` if lengths differ, preventing silent bugs from mismatched inputs.

User: How do you use `any` and `all`?
Joe: `all(x > 0 for x in nums)` checks if every element is positive. `any(x > 10 for x in nums)` checks if at least one element exceeds 10. Both short-circuit.

User: What is `super()` used for?
Joe: `super().__init__()` calls the parent class method. In Python 3, you don't need to pass arguments — it automatically uses the enclosing class and self. Essential in multiple inheritance.

User: How do you create an immutable class?
Joe: Use `@dataclass(frozen=True)` or implement `__setattr__` and `__delattr__` to raise `FrozenInstanceError`. Frozen dataclasses also generate `__hash__` automatically.

User: What is `__missing__` in dict subclasses?
Joe: `__missing__(self, key)` is called when `dict.__getitem__` can't find a key. Override it to provide default values or custom behavior, similar to `defaultdict` but with more control.

User: How do you use `collections.UserDict`?
Joe: `UserDict` is a base class for custom dict-like objects. Override methods like `__setitem__` and `__getitem__`. It handles the internal dict management for you, unlike inheriting from `dict` directly.

User: What is `typing.ParamSpec`?
Joe: `P = ParamSpec('P')` captures the parameter types of a function. Used with `TypeVar` to type decorators: `def decorator(f: Callable[P, T]) -> Callable[P, T]`.

User: How do you use `asyncio.to_thread`?
Joe: `await asyncio.to_thread(blocking_func, arg1)` runs a blocking function in a thread without blocking the event loop. It's a simple way to bridge sync and async code.

User: What is `contextlib.asynccontextmanager`?
Joe: `@asynccontextmanager` creates an async context manager from a generator. The generator must `yield` once, and cleanup goes in `finally` after the yield. Used with `async with`.

User: How do you use `pathlib.Path.stat`?
Joe: `Path("file.txt").stat()` returns a `os.stat_result` with `st_size`, `st_mtime`, etc. `stat().st_size` gives the file size in bytes.

User: What is `types.ModuleType`?
Joe: `types.ModuleType("mymod")` creates a new module object programmatically. Useful for dynamic module creation in plugin systems or when building importable objects at runtime.

User: How do you use `dis` module?
Joe: `dis.dis(func)` displays the bytecode instructions of a function. Useful for understanding what Python compiles your code to and for performance optimization.

User: What is `sys.intern`?
Joe: `sys.intern(s)` ensures that only one copy of a string is stored in memory. Useful when processing many duplicate strings like identifiers or symbols to save memory.

User: How do you handle `DeprecationWarning`?
Joe: `warnings.filterwarnings("ignore", category=DeprecationWarning)` suppresses them. Use `warnings.warn("Use new_func instead", DeprecationWarning)` to issue them in your own code.

User: What is `abc.abstractmethod`?
Joe: `@abstractmethod` marks a method as required to be implemented by subclasses. The class becomes abstract and can't be instantiated until all abstract methods are overridden.

User: How do you use `importlib.metadata`?
Joe: `metadata("requests")` returns package metadata including version, author, and dependencies. `entry_points()` discovers installed plugins. Available in Python 3.8+.

User: What is `__init_subclass__` used for?
Joe: `__init_subclass__(cls, **kwargs)` is called on subclass creation. It's cleaner than metaclasses for adding behavior to subclasses like auto-registration or validation.

User: How do you create a type alias for a complex type?
Joe: `type UserMap = dict[str, list[User]]` in Python 3.12+, or `UserMap: TypeAlias = dict[str, list[User]]` in 3.10+. This makes complex type hints reusable and readable.

User: What is `typing.TypeGuard`?
Joe: `def is_str_list(val: list[object]) -> TypeGuard[list[str]]:` tells the type checker that if the function returns True, the argument is safely narrowed to `list[str]`. Used for custom type narrowing.

User: How do you use `__classcell__`?
Joe: `__classcell__` is a closure variable that passes the class namespace to metaclasses. It's automatically set when using `super()` or `__init_subclass__` in a class body. Don't set it manually.

User: What is `typing.NamedTuple` vs `collections.namedtuple`?
Joe: `typing.NamedTuple` supports type annotations and default values: `class Point(NamedTuple): x: int = 0`. `collections.namedtuple` is the older runtime-only version without type checking.

User: How do you use `configparser` module?
Joe: `config = configparser.ConfigParser(); config.read('config.ini')` reads INI files. Access with `config['section']['key']`. Write with `config.write(open('config.ini', 'w'))`.

User: What is `shelve` module?
Joe: `shelve.open("db")` creates a persistent dictionary-like object. Store with `db["key"] = value`, retrieve with `db["key"]`. It's a simple key-value store backed by pickle.

User: How do you use `sqlite3` module?
Joe: `conn = sqlite3.connect("db.sqlite"); conn.execute("CREATE TABLE t(id INT)")` works with SQL directly. Use `conn.fetchall()` after `execute()` to get results.

User: What is `unittest.mock` for?
Joe: `@patch('module.func')` replaces a function with a `MagicMock` during testing. Track calls with `mock.assert_called_with(args)`. Essential for isolating unit tests from external dependencies.

User: How do you use `pathlib` with `open`?
Joe: `Path("file.txt").open("r", encoding="utf-8")` returns a file object like built-in `open()`. But `read_text()` and `write_text()` are usually more convenient for reading/writing entire files.

User: What is `__fspath__`?
Joe: `__fspath__` makes an object usable with `os.fspath()` and `pathlib`. If your class implements `__fspath__`, it can be used directly in `open()` and path operations.

User: How do you use `typing.Protocol` for duck typing?
Joe: `class Renderable(Protocol): def render(self) -> str: ...` defines a structural interface. Any class with a `render` method satisfies it without explicit inheritance, enabling static duck typing.

User: What is `contextlib.nullcontext`?
Joe: `nullcontext(enter_result)` is a no-op context manager that returns a value. Useful as a default when a function optionally needs a context manager: `with cm or nullcontext(val): ...`.

User: How do you use `struct` module?
Joe: `struct.pack("ii", 1, 2)` packs integers into bytes. `struct.unpack("ii", data)` unpacks. Useful for binary protocols and file formats with fixed-size fields.

User: What is `io.StringIO` and `io.BytesIO`?
Joe: `StringIO("text")` creates an in-memory text stream. `BytesIO(b"data")` creates a binary stream. Both behave like files and are useful for testing and manipulating string/byte data.

User: How do you use `contextlib.contextmanager` for resource management?
Joe: `@contextmanager def managed(): resource = acquire(); try: yield resource; finally: release(resource)` ensures cleanup runs even if exceptions occur. The try/finally pattern is essential.

User: What is `typing.Final` and when should you use it?
Joe: `MAX_SIZE: Final = 100` declares a value as a constant. Type checkers will flag any attempt to reassign it. Use it for module-level or class-level constants.

User: How do you use `functools.cached_property`?
Joe: `@cached_property` computes a value on first access and caches it as an instance attribute. Unlike `lru_cache`, it doesn't need arguments and works naturally with methods.

User: What is `typing.ClassVar`?
Joe: `count: ClassVar[int] = 0` marks a variable as class-level, not instance-level. It tells type checkers this attribute belongs to the class, not individual instances.

User: How do you use `__init_subclass__` for auto-registration?
Joe: Define `__init_subclass__(cls, **kwargs)` to register subclasses in a registry dict automatically. No metaclass needed — each subclass is registered when the class body is executed.

User: What is the purpose of `__new__` vs `__init__`?
Joe: `__new__` creates the instance (it's a static method). `__init__` initializes it after creation. `__new__` is used for immutable types like `str` and `int`, or for singletons.

User: How do you make a class immutable?
Joe: Implement `__setattr__` to raise `AttributeError` for all attribute assignments, or use `@dataclass(frozen=True)`. Also override `__delattr__` and `__hash__` for completeness.

User: What is `__repr__` vs `__str__`?
Joe: `__repr__` returns an unambiguous string representation, ideally one that could recreate the object: `Point(1, 2)`. `__str__` returns a readable string for end users: `(1, 2)`.

User: How do you use `__enter__` with a try/finally pattern manually?
Joe: `mgr = MyContext(); try: resource = mgr.__enter__(); use(resource); finally: mgr.__exit__(*sys.exc_info())`. The `with` statement does this automatically and handles exceptions correctly.

User: What is `typing.TypeAlias` and when do you use it?
Joe: `Vector: TypeAlias = list[float]` declares a type alias. It signals to type checkers that `Vector` is a type, not a variable. In Python 3.12+ use the `type` statement instead.

User: How do you use `collections.defaultdict` with a lambda?
Joe: `defaultdict(lambda: "N/A")` provides a default string for missing keys. `defaultdict(lambda: defaultdict(list))` creates nested defaultdicts for multi-level grouping.

User: What is `itertools.tee`?
Joe: `tee(iterable, n)` creates n independent iterators from a single iterable. Useful when you need to iterate over the same data multiple times. Memory grows with how far ahead you read.

User: How do you handle `KeyboardInterrupt` gracefully?
Joe: Wrap the main loop in `try: main() except KeyboardInterrupt: print("Bye"); sys.exit(0)`. Always catch it at the top level and clean up resources before exiting.

User: What is `typing.Protocol` with `runtime_checkable`?
Joe: `@runtime_checkable class Drawable(Protocol): def draw(self) -> None: ...` enables `isinstance(obj, Drawable)`. Only checks for method existence, not signatures, at runtime.

User: How do you use `os.makedirs` and `os.makedirs exist_ok`?
Joe: `os.makedirs("a/b/c", exist_ok=True)` creates nested directories without error if they exist. It's equivalent to `mkdir -p` in shell. The `exist_ok` parameter prevents `FileExistsError`.

User: What is `fileinput` module?
Joe: `fileinput.input(files=["a.txt", "b.txt"])` iterates over lines from multiple files. `fileinput.filename()` gives the current file name. Useful for processing multiple input files like shell tools.

User: How do you use `typing.Protocol` for callback signatures?
Joe: Define a protocol matching the expected callable: `class Handler(Protocol): def __call__(self, event: Event) -> None: ...`. This is more explicit than `Callable[[Event], None]` when adding attributes.

User: What is `decimal.localcontext`?
Joe: `with localcontext() as ctx: ctx.prec = 50; result = Decimal(1) / Decimal(3)` temporarily sets precision for decimal calculations. The context is restored when the block exits.

User: How do you use `enum.unique`?
Joe: `@unique class Color(Enum): RED = 1; GREEN = 2` raises `ValueError` if any values are duplicated. It catches copy-paste errors in enum definitions.

User: What is `typing.Unpack`?
Joe: `Unpack[TypedDict]` lets you type-annotate `**kwargs` with a TypedDict. It provides precise keyword argument types when the function accepts a variable set of named parameters.

User: How do you use `dataclasses.field` with `compare=False`?
Joe: `field(compare=False)` excludes a field from `__eq__` and `__lt__` comparisons. Useful for fields like timestamps that shouldn't affect equality semantics.

User: What is `__format__` method?
Joe: `__format__(self, format_spec)` is called by `format(obj, spec)`. A class can define custom formatting: `format(price, ".2f")` delegates to `price.__format__(".2f")`.

User: How do you use `typing.runtime_checkable` with `Protocol`?
Joe: Adding `@runtime_checkable` to a Protocol enables `isinstance` checks at runtime. Without it, `isinstance(obj, MyProtocol)` raises `TypeError`. Only structural presence is checked, not types.

User: What is `hashlib.pbkdf2_hmac`?
Joe: `hashlib.pbkdf2_hmac("sha256", password, salt, iterations=100000)` derives a key from a password using PBKDF2. Always use this or `bcrypt` instead of plain hashing for passwords.

User: How do you use `typing.Concatenate`?
Joe: `Concatenate[ParamSpec, str]` adds parameters to the front of a ParamSpec. Useful for typing decorators that add parameters: `def with_db(f: Callable[P, T]) -> Callable[Concatenate[DB, P], T]`.

User: What is `pathlib.PurePath`?
Joe: `PurePath("a/b")` provides path manipulation without touching the filesystem. Use it for parsing and constructing paths when you don't need I/O operations like `exists()` or `read_text()`.

User: How do you use `collections.abc.Mapping`?
Joe: `Mapping` defines the read-only dict interface: `__getitem__`, `__len__`, `__iter__`, `keys`, `values`, `items`, `get`, `__contains__`. Subclass it to create custom read-only mappings.

User: What is the difference between `Mapping` and `MutableMapping`?
Joe: `MutableMapping` adds `__setitem__`, `__delitem__`, `pop`, `popitem`, `clear`, `update`, `setdefault` to the `Mapping` interface. Use `MutableMapping` for dictionaries you can modify.

User: How do you use `abc.ABCMeta`?
Joe: `ABCMeta` is the metaclass for `ABC`. `isinstance(obj, ABCMeta)` checks if a class uses it. You can combine it with other metaclasses: `class Meta(ABCMeta, OtherMeta)`.

User: What is `contextlib.ContextDecorator`?
Joe: A mixin that makes a context manager also work as a decorator. Implement `__enter__` and `__exit__` as normal, and the instance can be used with both `with` and `@` syntax.

User: How do you use `pathlib.Path` with `open` for CSV?
Joe: Combine with the csv module: `with Path("data.csv").open() as f: reader = csv.DictReader(f); for row in reader: process(row)`. Or use `csv.reader(Path("data.csv").open())`.

User: What is `typing.NamedTuple` with defaults?
Joe: `class Point(NamedTuple): x: int; y: int = 0` gives `y` a default value. Fields with defaults must come after fields without defaults, just like function parameters.

User: How do you use `__contains__` for custom membership testing?
Joe: Define `def __contains__(self, item): return item in self._data` to customize `in` operator behavior. For example, a `Range` class could efficiently check if a number is within bounds.

User: What is `typing.TypeAlias` used for in real code?
Joe: `type Vector = list[float]` (3.12+) or `Vector: TypeAlias = list[float]` (3.10+) gives a meaningful name to complex types. It improves readability: `def scale(v: Vector, s: float) -> Vector`.

User: How do you use `os.path.relpath`?
Joe: `os.path.relpath("/a/b/c.txt", "/a")` returns `"b/c.txt"`. It computes the relative path from a start directory to a target path, useful for display or portable references.

User: What is `struct.pack_into`?
Joe: `struct.pack_into("ii", buffer, offset, a, b)` packs data directly into a pre-allocated buffer at a given offset. More memory-efficient than `pack` when building large binary messages.

User: How do you use `io.BufferedReader` and `io.BufferedWriter`?
Joe: `BufferedReader(raw_file)` reads data in chunks for efficiency. `BufferedWriter(raw_file)` buffers writes. Both reduce system calls. The built-in `open()` uses buffering by default.

User: What is `typing.Unpack` with `TypedDict`?
Joe: `Unpack[MyTypedDict]` annotates `**kwargs` with specific types. `def f(**kwargs: Unpack[MyTypedDict])` tells type checkers exactly which keyword arguments are expected and their types.

User: How do you create a dynamic property?
Joe: Use `@property` with a custom `__getattr__`. Or use descriptors: define a class with `__get__` and assign it to a class attribute. Both approaches allow computed attributes.

User: What is `abc.abstractproperty`?
Joe: `abstractproperty` is deprecated. Use `@property` combined with `@abstractmethod` instead: `@property @abstractmethod def value(self): ...`. This enforces that subclasses implement the property.

User: How do you use `inspect.signature`?
Joe: `sig = inspect.signature(my_func); sig.parameters` gives an OrderedDict of Parameter objects. Each parameter has `name`, `annotation`, `default`, and `kind` (POSITIONAL_OR_KEYWORD, etc.).

User: What is `typing.get_origin` and `typing.get_args`?
Joe: `get_origin(list[int])` returns `list`. `get_args(list[int])` returns `(int,)`. Useful for introspecting generic types at runtime to build adapters or serializers.

User: How do you use `pathlib.Path.mkdir` with parents?
Joe: `Path("a/b/c").mkdir(parents=True, exist_ok=True)` creates all intermediate directories. `parents=True` is like `mkdir -p`. `exist_ok=True` prevents errors if the directory already exists.

User: What is `typing.ParamSpec` for decorators?
Joe: `P = ParamSpec('P')` captures parameter types. `def decorator(f: Callable[P, int]) -> Callable[P, str]: ...` preserves the decorated function's parameter types for type checkers.

User: How do you use `dataclasses.KW_ONLY`?
Joe: Fields after `KW_ONLY` must be passed as keyword arguments. `@dataclass class User: name: str; KW_ONLY; age: int` means `User("Alice", age=30)` requires `age` as keyword.

User: What is `__abstractmethods__` set?
Joe: `cls.__abstractmethods__` is a frozenset of method names that are abstract. A class can only be instantiated when this set is empty. It's set by `ABCMeta` when abstract methods are defined.

User: How do you use `typing.assert_type`?
Joe: `assert_type(value, int)` tells the type checker that `value` must be `int`. If the checker disagrees, it raises an error. It's purely for static analysis and has no runtime effect.

User: What is `typing.assert_never`?
Joe: `assert_never(value)` is used after exhaustive type checking. If the type checker can prove the code is reachable, it flags an error. It ensures all enum cases or union branches are handled.

User: How do you use `functools.reduce` with an initial value?
Joe: `reduce(lambda a, b: a + b, [1,2,3], 0)` starts with initial value 0. Without an initial value, the first element is used as the accumulator start, and the iterable must not be empty.

User: What is `__del__` and when should you use it?
Joe: `__del__` is a finalizer called when an object is garbage collected. Avoid it for critical cleanup — use context managers instead. The timing of `__del__` is not guaranteed, especially with reference cycles.

User: How do you use `weakref` module?
Joe: `weakref.ref(obj)` creates a weak reference that doesn't prevent garbage collection. Use `ref()` to get the object or None. Weak references are essential for caches and observer patterns.

User: What is `__delattr__` used for?
Joe: `__delattr__(self, name)` is called when `del obj.name` executes. Override it to prevent deletion of attributes or to implement custom deletion behavior, like removing from a database.

User: How do you use `typing.TypeAlias` with forward references?
Joe: `MyType: TypeAlias = "SomeClass"` allows forward references in type aliases. The string is lazily evaluated when the type hint is accessed, resolving circular import issues.

User: What is `pathlib.Path.walk`?
Joe: `Path("dir").walk()` yields `(dirpath, dirnames, filenames)` for each directory. It's the pathlib equivalent of `os.walk`. Available in Python 3.12+.

User: How do you use `functools.total_ordering` correctly?
Joe: Define `__eq__` and exactly one of `__lt__`, `__le__`, `__gt__`, `__ge__`. The decorator generates the rest. Defining more than one comparison besides `__eq__` causes inconsistent results.

User: What is `typing.overload` and when to use it?
Joe: Use `@overload` when a function returns different types based on input. Define multiple signatures with `@overload`, then one actual implementation. Type checkers use the overloads for narrowing.

User: How do you use `collections.abc.Sequence`?
Joe: `Sequence` defines `__getitem__`, `__len__`, `index`, and `count`. It's the type for read-only list-like objects. `MutableSequence` adds `__setitem__`, `__delitem__`, `append`, `insert`, etc.

User: What is `dataclasses.replace`?
Joe: `replace(instance, x=5)` creates a new dataclass instance with some fields changed. It's useful for modifying frozen dataclasses since direct assignment raises an error.

User: How do you use `importlib.resources`?
Joe: `importlib.resources.files("package").joinpath("data.txt").read_text()` accesses package data files. It works correctly with zipped packages and is the recommended way to read package resources.

User: What is `abc.abstractstaticmethod`?
Joe: `abstractstaticmethod` doesn't exist. Use `@staticmethod` combined with `@abstractmethod`: apply `@staticmethod` first, then `@abstractmethod`. The order matters for correct behavior.

User: How do you use `typing.runtime_checkable` with `Iterable`?
Joe: `@runtime_checkable class MyIterable(Protocol): def __iter__(self): ...` enables `isinstance(obj, MyIterable)`. Any object with `__iter__` will pass, providing runtime structural typing.

User: What is `pathlib.PurePosixPath` and `PureWindowsPath`?
Joe: `PurePosixPath("a/b")` uses forward slashes. `PureWindowsPath("a\\b")` uses backslashes. They let you construct paths for a target OS regardless of your current platform.

User: How do you use `collections.deque` with maxlen?
Joe: `deque(maxlen=1000)` automatically discards items from the opposite end when full. Perfect for sliding windows or recent-history buffers: `buf.append(item)` evicts the oldest when full.

User: What is `sys.setrecursionlimit`?
Joe: `sys.setrecursionlimit(5000)` increases the max recursion depth (default 1000). Use it carefully — setting it too high can cause a segfault. Prefer iterative solutions when possible.

User: How do you use `typing.TypeVar` with bounds?
Joe: `T = TypeVar('T', bound=Number)` restricts `T` to `Number` or its subclasses. `T = TypeVar('T', int, str)` restricts `T` to exactly `int` or `str`. Both are for constrained generics.

User: What is `dataclasses.field` with `repr=False`?
Joe: `field(repr=False)` excludes a field from the auto-generated `__repr__`. Useful for sensitive data like passwords or fields with circular references that can't be safely displayed.

User: How do you use `collections.abc.Callable` for type hints?
Joe: `Callable[[int, str], bool]` from `collections.abc` is preferred over `typing.Callable` for Python 3.9+. It has the same syntax but doesn't require importing from the `typing` module.

User: What is `typing.Self`?
Joe: `Self` (Python 3.11+) represents the type of the current class. `def copy(self) -> Self:` means the method returns the same type as the instance. Useful for method chaining in subclasses.

User: How do you use `pathlib.Path.suffix` and `suffixes`?
Joe: `Path("archive.tar.gz").suffix` returns `".gz"`. `Path("archive.tar.gz").suffixes` returns `[".tar", ".gz"]`. `stem` gives the name without the last suffix: `"archive.tar"`.

User: What is `typing.Required` and `typing.NotRequired`?
Joe: `Required[int]` marks a TypedDict key as mandatory even in total=False mode. `NotRequired[str]` marks it as optional. In Python 3.11+ they're available in `typing`.

User: How do you use `os.path.splitext`?
Joe: `os.path.splitext("file.tar.gz")` returns `("file.tar", ".gz")`. It splits at the last dot. For all extensions use `pathlib`'s `.suffixes`.

User: What is `contextlib.AsyncExitStack`?
Joe: `AsyncExitStack` manages a dynamic collection of async (and sync) context managers. Use `await stack.enter_async_context(cm)` to add them, all cleaned up on exit.

User: How do you use `typing.NamedTuple` with `__doc__`?
Joe: `class User(NamedTuple): """A user.""" name: str; age: int` sets the docstring. The `__doc__` attribute of the class will be "A user.", helping with documentation tools.

User: What is `dataclasses.field` with `init=False`?
Joe: `field(init=False, default=0)` excludes the field from `__init__` and provides a default. The field is initialized directly in the class body. Useful for computed or derived fields.

User: How do you use `sys.modules`?
Joe: `sys.modules` is a dict mapping module names to module objects. `sys.modules["os"]` gives the os module. Insert a mock: `sys.modules["missing"] = fake_module` to handle missing dependencies.

User: What is `typing.Unpack` in Python 3.11+?
Joe: `Unpack[TypedDict]` typed `**kwargs` with specific keys and types. It bridges TypedDicts with function signatures for precise keyword argument validation.

User: How do you use `functools.lru_cache` on a method with mutable arguments?
Joe: Convert mutable arguments to hashable: `@lru_cache def process(items_key: tuple): ...` and call with `process(tuple(items))`. The arguments must be hashable to be cached.

User: What is `__init_subclass__` signature?
Joe: `__init_subclass__(cls, **kwargs)` receives the new subclass as `cls`. Parent-passed kwargs like `class Child(Parent, tag="x")` arrive in `kwargs`. Call `super().__init_subclass__(**kwargs)`.

User: How do you use `typing.TypeVar` with constraints?
Joe: `T = TypeVar('T', int, float)` restricts `T` to only `int` or `float`. Unlike `bound`, it doesn't allow subclasses. Useful when only specific types should be accepted.

User: What is `typing.Final` on a class attribute?
Joe: `class Config: DEBUG: Final[bool] = True` marks `DEBUG` as unchangeable. Type checkers prevent `Config.DEBUG = False` even though Python allows it at runtime.

User: How do you use `pathlib.Path.with_suffix`?

User: What is `typing.Required` for TypedDict?
Joe: `class User(TypedDict, total=False): name: Required[str]; age: int` makes `name` mandatory even though the class defaults to all-optional. Useful when most fields are optional.

User: How do you use `abc.ABC` as a base class?
Joe: `class Base(ABC): @abstractmethod def compute(self): pass` creates an abstract base class. Any subclass must implement `compute` or remain abstract. Prevents instantiation of incomplete classes.

User: What is `functools.wraps` and what attributes does it copy?
Joe: `@wraps(f)` copies `__module__`, `__name__`, `__qualname__`, `__doc__`, `__dict__`, and `__wrapped__` from the original function. It preserves the decorated function's identity and documentation.

User: How do you use `typing.TypeGuard` for type narrowing?
Joe: `def is_str(val: object) -> TypeGuard[str]: return isinstance(val, str)` narrows the type in the caller. After `if is_str(x):`, the type checker knows `x` is `str` in the if-block.

User: How do you use `pathlib.Path.exists`?

User: What is `pathlib.Path.is_absolute`?

User: How do you use `typing.Required` and `NotRequired` with TypedDict?
