User: How do I reverse a list in Python?
Joe: Use list slicing to reverse: reversed_list = my_list[::-1]. You can also call my_list.reverse() to reverse in place, or use the built-in function reversed() which returns an iterator.

User: How do I read a file in Python?
Joe: Open the file with a with statement: with open('file.txt', 'r') as f: content = f.read(). Using the with statement ensures the file is properly closed even if an error occurs. You can also use f.readlines() to get a list of lines.

User: How do I write to a file in Python?
Joe: Use the with statement: with open('file.txt', 'w') as f: f.write('hello'). The 'w' mode creates or overwrites the file. Use 'a' mode to append without overwriting.

User: What is a dictionary in Python?
Joe: A dictionary is a collection of key-value pairs. Create one with: d = {'key': 'value'}. Access values with d['key'] or d.get('key'). Dictionaries are unordered (before Python 3.7) and fast for lookups.

User: How do I loop through a dictionary?
Joe: Use for key in d: to iterate over keys, for key, value in d.items(): for both keys and values, for value in d.values(): for just values, and for key in d.keys(): explicitly for keys.

User: What is a list comprehension?
Joe: A list comprehension creates a new list from an expression: [x*2 for x in range(10)]. You can add conditions: [x for x in range(10) if x % 2 == 0]. They are concise and usually faster than equivalent for loops.

User: What is the difference between a list and a tuple?
Joe: Lists are mutable (can be changed after creation) and use square brackets. Tuples are immutable (cannot be changed) and use parentheses. Tuples are faster and can be used as dictionary keys. Lists are for collections that change, tuples for fixed records.

User: How do I handle exceptions in Python?
Joe: Use try/except blocks: try: risky_code() except ValueError as e: handle_error(e). You can add finally for cleanup code that runs regardless. Multiple except blocks catch different error types.

User: What is a lambda function?
Joe: A lambda is an anonymous function: add = lambda a, b: a + b. Lambdas are limited to a single expression and are best used for short throwaway functions, often as arguments to sort(), map(), or filter().

User: What is the difference between 'is' and '==' in Python?
Joe: '==' checks if two values are equal. 'is' checks if two variables point to the exact same object in memory. Use '==' for value comparison and 'is' only for checking None or singleton instances.

User: How do I install a Python package?
Joe: Use pip: pip install package_name. For user installations: pip install --user package_name. Create virtual environments with python -m venv env to isolate project dependencies.

User: What is a virtual environment?
Joe: A virtual environment is an isolated Python environment with its own packages and Python version. Create one with python -m venv env, activate with source env/bin/activate (Linux/Mac) or env\Scripts\activate (Windows). It prevents package conflicts between projects.

User: How do I create a class in Python?
Joe: Use the class keyword: class Dog: def __init__(self, name): self.name = name. The __init__ method is the constructor. Methods are functions defined inside the class with self as the first parameter.

User: What is __init__ in Python?
Joe: __init__ is the constructor method called when creating a new object. It initializes the object's attributes. def __init__(self, name): self.name = name. It runs automatically when you call ClassName(arguments).

User: What is the *args and **kwargs syntax?
Joe: *args collects positional arguments into a tuple. **kwargs collects keyword arguments into a dictionary. def func(*args, **kwargs): lets a function accept any number of arguments. They must appear in that order.

User: How do I read a CSV file in Python?
Joe: Use the csv module: import csv; with open('data.csv') as f: reader = csv.reader(f); for row in reader: print(row). Or use pandas: import pandas as pd; df = pd.read_csv('data.csv').

User: What is the difference between map() and a list comprehension?
Joe: Both apply a function to each item in an iterable. map(func, iterable) returns a map object (lazy iterator). A list comprehension [func(x) for x in iterable] returns a list directly. List comprehensions are generally preferred for readability.

User: How do I sort a list in Python?
Joe: Use sorted() for a new sorted list: sorted(my_list). Use my_list.sort() to sort in place. Add key parameter for custom sort: sorted(my_list, key=len). Add reverse=True for descending order.

User: What is the difference between append and extend?
Joe: append adds a single element to the end of a list. extend adds each element from an iterable to the list. [1,2].append([3,4]) gives [1,2,[3,4]]. [1,2].extend([3,4]) gives [1,2,3,4].

User: How do I check if a file exists?
Joe: Use os.path.exists('file.txt') or os.path.isfile('file.txt'). In Python 3.4+, use pathlib: Path('file.txt').exists(). For checking and creating directories, use os.makedirs('dir', exist_ok=True).

User: What is a decorator in Python?
Joe: A decorator is a function that modifies another function's behavior. Apply with @decorator_name above the function definition. Common examples include @property, @staticmethod, and @functools.wraps for preserving function metadata.

User: What is a generator in Python?
Joe: A generator is a function that yields values one at a time instead of returning all at once. Use yield instead of return. Generators are memory-efficient for large datasets because they produce values lazily on demand.

User: How do I merge two dictionaries?
Joe: In Python 3.9+: merged = dict1 | dict2. In earlier versions: merged = {**dict1, **dict2}. Or use dict1.update(dict2) to modify dict1 in place. Later values overwrite earlier ones for duplicate keys.
