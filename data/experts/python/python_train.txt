Joe: `pyproject.toml` is the modern Python project configuration file replacing `setup.py`. It specifies build system, dependencies, and tool configs like `[tool.pytest]` and `[tool.mypy]`.

User: What is the difference between venv and virtualenv?
Joe: `venv` is in the standard library and creates lightweight environments. `virtualenv` is a third-party tool that's faster, supports Python 2, and can create environments with older Pythons.

User: How do you use `pdb` for debugging?
Joe: Run `python3 -m pdb script.py` to start in debugger mode. Use `b` to set breakpoints, `n` for next line, `s` for step into, `c` to continue, `p expr` to print, and `q` to quit.

User: What does `breakpoint()` do?
Joe: `breakpoint()` is a built-in that drops into `pdb` at that line. In Python 3.7+, it's equivalent to `import pdb; pdb.set_trace()`. Set `PYTHONBREAKPOINT=0` to disable all breakpoints.

User: How do you use `traceback` module?
Joe: `traceback.print_exc()` prints the current exception's traceback. `traceback.format_exception(exc)` returns the traceback as a list of strings for custom handling.

User: What is `faulthandler`?
Joe: `import faulthandler; faulthandler.enable()` dumps tracebacks of all threads on a fatal error or segfault. It helps debug C-level crashes that don't produce Python tracebacks.

User: How do you use `threading` in Python?
Joe: `threading.Thread(target=func, args=(arg1,)).start()` creates and runs a thread. Use `thread.join()` to wait for completion. Note that the GIL limits true parallelism for CPU-bound tasks.

User: What is `multiprocessing`?
Joe: `multiprocessing.Process(target=func)` spawns a separate process with its own Python interpreter. It bypasses the GIL for true parallelism but has higher overhead than threads.

User: How does `concurrent.futures.ThreadPoolExecutor` work?
Joe: `with ThreadPoolExecutor(max_workers=4) as pool: futures = [pool.submit(work, item) for item in data]`. Use `as_completed(futures)` or `future.result()` to get results.

User: What is `ProcessPoolExecutor`?
Joe: `ProcessPoolExecutor` works like `ThreadPoolExecutor` but uses processes instead of threads, bypassing the GIL. Ideal for CPU-bound tasks that can be parallelized.

User: How does `asyncio` work?
Joe: `async def fetch(): await aiohttp.get(url)` defines a coroutine. Run with `asyncio.run(main())`. `await` suspends execution until the awaited coroutine completes, allowing other tasks to run.

User: What is an async event loop?
Joe: `asyncio.run(main())` creates an event loop, runs the coroutine, and closes the loop. The loop schedules and runs coroutines cooperatively, switching between them at `await` points.

User: How do you run multiple coroutines concurrently?
Joe: `await asyncio.gather(coroutine1(), coroutine2())` runs them concurrently and returns results in order. `asyncio.create_task(coro)` schedules a coroutine without blocking.

User: What are async generators?
Joe: `async def gen(): yield await fetch_data()` is an async generator. Iterate with `async for item in gen()`. Useful for streaming data from async sources.

User: How do you write a custom JSON encoder?
Joe: Subclass `json.JSONEncoder` and override `default(self, obj)`: `def default(self, obj): if isinstance(obj, datetime): return obj.isoformat(); return super().default(obj)`.

User: What are JSON Lines?
Joe: JSON Lines is one JSON object per line. Read with: `for line in f: data.append(json.loads(line))`. Write with: `f.write(json.dumps(obj) + '\n')`. It's useful for streaming large datasets.

User: How do you handle timezones in datetime?
Joe: `from datetime import timezone; dt = datetime.now(timezone.utc)` gets UTC time. Use `dt.astimezone(tz)` to convert. The `pytz` or `dateutil` library provides named timezones.

User: What is `dateutil.parser`?
Joe: `dateutil.parser.parse("March 14, 2026")` parses various date string formats automatically. It handles many formats that `strptime` can't without explicit format strings.

User: What is `sys.path`?
Joe: `sys.path` is the list of directories Python searches for modules. `sys.path.insert(0, '/my/libs')` adds a directory to the front. It's initialized from `PYTHONPATH` and installed packages.

User: How do you use `platform` module?
Joe: `platform.python_version()` returns the Python version string. `platform.system()` returns 'Linux', 'Darwin', or 'Windows'. Useful for platform-specific behavior.

User: How do you profile Python code?
Joe: `cProfile.run("my_func()")` shows function call statistics. `python3 -m cProfile script.py` profiles the entire script. Use `snakeviz` to visualize the results.

User: What is `memory_profiler`?
Joe: `@profile` decorator from `memory_profiler` tracks memory usage line by line. Run with `python3 -m memory_profiler script.py` to see memory consumption at each line.

User: How do you use `functools.reduce` to flatten a nested list?
Joe: `reduce(lambda a, b: a + b, nested_list)` flattens one level. For deep flattening: `def flatten(lst): return [x for item in lst for x in (flatten(item) if isinstance(item, list) else [x])]`.

User: What is `inspect` module used for?
Joe: `inspect.getsource(func)` retrieves source code. `inspect.signature(func)` gets function parameters. `inspect.stack()` shows the call stack. Useful for debugging and metaprogramming.

User: How do you create a singleton class in Python?
Joe: Override `__new__`: `def __new__(cls): if not hasattr(cls, '_inst'): cls._inst = super().__new__(cls); return cls._inst`. Alternatively, use a module-level variable.

User: How do you use `collections.abc` for abstract base classes?
Joe: `from collections.abc import Iterable, Mapping`. Use `isinstance(obj, Iterable)` to check if an object is iterable. These are more reliable than checking for specific types.

User: What is the `abc.ABC` class?
Joe: Inherit from `ABC` and use `@abstractmethod` to define required methods: `class Base(ABC): @abstractmethod def compute(self): ...`. You can't instantiate a class with unimplemented abstract methods.

User: How do you use `typing.runtime_checkable`?
Joe: `@runtime_checkable class MyProtocol(Protocol): ...` makes `isinstance(obj, MyProtocol)` work at runtime. Without it, Protocol only works for static type checking.

User: What is `asyncio.Queue`?
Joe: `asyncio.Queue()` is an async-safe FIFO queue. `await queue.put(item)` adds items, `await queue.get()` retrieves them. It's used to coordinate producer and consumer coroutines.

User: How do you limit concurrency with `asyncio.Semaphore`?
Joe: `sem = asyncio.Semaphore(10)` limits to 10 concurrent operations. Use `async with sem:` before awaiting the operation. This prevents overwhelming external services.

User: What is `numpy` and its basic data structure?
Joe: `numpy.array([1,2,3])` creates an ndarray, a homogeneous N-dimensional array. It supports vectorized operations: `arr * 2` multiplies all elements without explicit loops.

User: How does numpy broadcasting work?
Joe: Broadcasting automatically aligns arrays of different shapes for operations: `np.array([1,2,3]) + 10` adds 10 to each element. Shapes are aligned from the right, with size-1 dimensions expanded.

User: How do you index numpy arrays?
Joe: `arr[0]` gets the first element, `arr[1:4]` slices, `arr[arr > 5]` boolean indexes, `arr[[0,2,5]]` fancy indexes. Multi-dimensional: `arr[0, :]` gets the first row.

User: What are numpy dtypes?
Joe: `np.array([1,2,3], dtype=np.float32)` specifies the data type. Common dtypes: `int32`, `float64`, `complex128`, `bool_`. Using smaller dtypes like `float16` saves memory.

User: What is `argparse`'s `nargs` parameter?
Joe: `nargs='+'` requires one or more arguments, `nargs='*'` accepts zero or more, `nargs=3` requires exactly three. `nargs='?'` makes the argument optional with an optional default.

User: How do you handle signals in Python?
Joe: `signal.signal(signal.SIGINT, handler)` registers a handler for the SIGINT signal. The handler receives the signal number and frame. Return to the interrupted code.

User: What is `hashlib` for?
Joe: `hashlib.sha256(b"data").hexdigest()` computes a SHA-256 hash. Used for password hashing (with salt), data integrity checks, and creating unique identifiers.

User: How do you use `pathlib` to walk directories?
Joe: `Path("dir").rglob("*.py")` recursively finds all Python files. `Path("dir").iterdir()` lists immediate children. `Path("dir").glob("*")` matches non-recursively.

User: What is `shutil.make_archive`?
Joe: `shutil.make_archive("backup", "zip", "source_dir")` creates a zip archive of a directory. Supports formats: zip, tar, gztar, bztar, xztar.

User: How do you use `decimal.Decimal` for precise arithmetic?
Joe: `Decimal("0.1") + Decimal("0.2")` gives exactly `0.3`, unlike float. Always construct from strings, not floats: `Decimal(0.1)` already has float imprecision.

User: What is `fractions.Fraction`?
Joe: `Fraction(1, 3)` represents one-third exactly. Supports arithmetic: `Fraction(1, 3) + Fraction(1, 6)` gives `Fraction(1, 2)`. Useful when floating-point precision isn't acceptable.

User: How do you use `itertools.zip_longest`?
Joe: `zip_longest([1,2], [3], fillvalue=0)` gives (1,3), (2,0). It pads the shorter iterable with the fill value instead of stopping at the shortest one like `zip`.

User: What is `itertools.islice`?
Joe: `islice(iterable, 10, 20)` slices an iterator like a list slice. It works on any iterable, not just sequences, and avoids materializing the whole thing in memory.

User: What is `bisect` module?
Joe: `bisect.bisect_left(sorted_list, x)` finds the insertion point for `x` in sorted order. `bisect.insort(sorted_list, x)` inserts while maintaining sorted order. Both are O(log n).

User: How do you use `collections.ChainMap`?
Joe: `ChainMap(dict1, dict2)` treats multiple dicts as one, with the first dict taking priority. Useful for merging configuration layers: defaults, config file, environment variables.

User: What is `typing.NamedTuple`?
Joe: `Point = NamedTuple('Point', [('x', int), ('y', int)])` creates a typed namedtuple. It's equivalent to defining a class but with tuple behavior and type annotations.

User: How do you use `dataclasses.asdict`?
Joe: `dataclasses.asdict(instance)` recursively converts a dataclass instance to a dictionary. Useful for JSON serialization or passing dataclass fields as keyword arguments.

User: What is `__class_getitem__`?
Joe: `__class_getitem__` allows a class to be parameterized with brackets: `class Stack: def __class_getitem__(cls, item): return cls`. This enables `Stack[int]` syntax.

User: How do you use `typing.TYPE_CHECKING`?
Joe: `if TYPE_CHECKING:` imports only during static analysis. It's used to import types for annotations without creating circular imports or runtime overhead.

User: What is `typing.overload`?
Joe: `@overload` declares multiple type signatures for a function. The actual implementation is untyped. It helps type checkers understand functions with different return types based on arguments.

User: What is `__dataclass_fields__`?
Joe: `cls.__dataclass_fields__` is a dict of field name to Field objects. It's automatically generated by `@dataclass` and useful for introspection of dataclass structure.

User: What is `importlib` used for?
Joe: `importlib.import_module("os.path")` dynamically imports a module by string name. `importlib.reload(module)` re-imports a module after changes. Both are useful for plugin systems.

User: How do you create a Python package?
Joe: Create a directory with `__init__.py` (can be empty). Add modules as `.py` files. Use `pyproject.toml` for metadata. The directory name becomes the package name.

User: What is `__all__` in a module?
Joe: `__all__ = ['func1', 'func2']` defines what `from module import *` imports. It's a list of strings naming public API objects. It doesn't affect explicit imports.

User: How do you use `functools.lru_cache` with class methods?
Joe: Apply it to the method, but cache is shared across instances. To cache per-instance, use a custom wrapper. Alternatively, cache expensive computations in instance attributes.

User: What is `typing.get_type_hints`?
Joe: `get_type_hints(func)` returns the resolved type hints as a dict, evaluating forward references. It's useful for introspecting annotations in a portable way.

User: How do you use `__set_name__` for self-naming descriptors?
Joe: Define `__set_name__(self, owner, name)` in your descriptor class. Python calls it automatically when the class is created: `class Foo: attr = MyDescriptor()`. The descriptor now knows it's named "attr".

User: What is `operator` module?
Joe: `operator.add(1, 2)` is the function form of `+`. `operator.attrgetter('name')` creates a callable that gets the name attribute. Useful as arguments to `map`, `sorted`, `reduce`.

User: What is `__missing__` in dict subclasses?
Joe: `__missing__(self, key)` is called when `dict.__getitem__` can't find a key. Override it to provide default values or custom behavior, similar to `defaultdict` but with more control.

User: What is `typing.ParamSpec`?
Joe: `P = ParamSpec('P')` captures the parameter types of a function. Used with `TypeVar` to type decorators: `def decorator(f: Callable[P, T]) -> Callable[P, T]`.

User: How do you use `asyncio.to_thread`?
Joe: `await asyncio.to_thread(blocking_func, arg1)` runs a blocking function in a thread without blocking the event loop. It's a simple way to bridge sync and async code.

User: What is `contextlib.asynccontextmanager`?
Joe: `@asynccontextmanager` creates an async context manager from a generator. The generator must `yield` once, and cleanup goes in `finally` after the yield. Used with `async with`.

User: How do you use `pathlib.Path.stat`?
Joe: `Path("file.txt").stat()` returns a `os.stat_result` with `st_size`, `st_mtime`, etc. `stat().st_size` gives the file size in bytes.

User: What is `types.ModuleType`?
Joe: `types.ModuleType("mymod")` creates a new module object programmatically. Useful for dynamic module creation in plugin systems or when building importable objects at runtime.

User: How do you use `dis` module?
Joe: `dis.dis(func)` displays the bytecode instructions of a function. Useful for understanding what Python compiles your code to and for performance optimization.

User: What is `sys.intern`?
Joe: `sys.intern(s)` ensures that only one copy of a string is stored in memory. Useful when processing many duplicate strings like identifiers or symbols to save memory.

User: How do you handle `DeprecationWarning`?
Joe: `warnings.filterwarnings("ignore", category=DeprecationWarning)` suppresses them. Use `warnings.warn("Use new_func instead", DeprecationWarning)` to issue them in your own code.

User: What is `abc.abstractmethod`?
Joe: `@abstractmethod` marks a method as required to be implemented by subclasses. The class becomes abstract and can't be instantiated until all abstract methods are overridden.

User: How do you use `importlib.metadata`?
Joe: `metadata("requests")` returns package metadata including version, author, and dependencies. `entry_points()` discovers installed plugins. Available in Python 3.8+.

User: What is `typing.TypeGuard`?
Joe: `def is_str_list(val: list[object]) -> TypeGuard[list[str]]:` tells the type checker that if the function returns True, the argument is safely narrowed to `list[str]`. Used for custom type narrowing.

User: How do you use `__classcell__`?
Joe: `__classcell__` is a closure variable that passes the class namespace to metaclasses. It's automatically set when using `super()` or `__init_subclass__` in a class body. Don't set it manually.

User: What is `typing.NamedTuple` vs `collections.namedtuple`?
Joe: `typing.NamedTuple` supports type annotations and default values: `class Point(NamedTuple): x: int = 0`. `collections.namedtuple` is the older runtime-only version without type checking.

User: How do you use `configparser` module?
Joe: `config = configparser.ConfigParser(); config.read('config.ini')` reads INI files. Access with `config['section']['key']`. Write with `config.write(open('config.ini', 'w'))`.

User: What is `shelve` module?
Joe: `shelve.open("db")` creates a persistent dictionary-like object. Store with `db["key"] = value`, retrieve with `db["key"]`. It's a simple key-value store backed by pickle.

User: What is `unittest.mock` for?
Joe: `@patch('module.func')` replaces a function with a `MagicMock` during testing. Track calls with `mock.assert_called_with(args)`. Essential for isolating unit tests from external dependencies.

User: How do you use `pathlib` with `open`?
Joe: `Path("file.txt").open("r", encoding="utf-8")` returns a file object like built-in `open()`. But `read_text()` and `write_text()` are usually more convenient for reading/writing entire files.

User: What is `contextlib.nullcontext`?
Joe: `nullcontext(enter_result)` is a no-op context manager that returns a value. Useful as a default when a function optionally needs a context manager: `with cm or nullcontext(val): ...`.

User: What is `io.StringIO` and `io.BytesIO`?
Joe: `StringIO("text")` creates an in-memory text stream. `BytesIO(b"data")` creates a binary stream. Both behave like files and are useful for testing and manipulating string/byte data.

User: How do you use `functools.cached_property`?
Joe: `@cached_property` computes a value on first access and caches it as an instance attribute. Unlike `lru_cache`, it doesn't need arguments and works naturally with methods.

User: What is `typing.ClassVar`?
Joe: `count: ClassVar[int] = 0` marks a variable as class-level, not instance-level. It tells type checkers this attribute belongs to the class, not individual instances.

User: What is the purpose of `__new__` vs `__init__`?
Joe: `__new__` creates the instance (it's a static method). `__init__` initializes it after creation. `__new__` is used for immutable types like `str` and `int`, or for singletons.

User: How do you use `__enter__` with a try/finally pattern manually?
Joe: `mgr = MyContext(); try: resource = mgr.__enter__(); use(resource); finally: mgr.__exit__(*sys.exc_info())`. The `with` statement does this automatically and handles exceptions correctly.

User: How do you use `collections.defaultdict` with a lambda?
Joe: `defaultdict(lambda: "N/A")` provides a default string for missing keys. `defaultdict(lambda: defaultdict(list))` creates nested defaultdicts for multi-level grouping.

User: How do you handle `KeyboardInterrupt` gracefully?
Joe: Wrap the main loop in `try: main() except KeyboardInterrupt: print("Bye"); sys.exit(0)`. Always catch it at the top level and clean up resources before exiting.

User: What is `fileinput` module?
Joe: `fileinput.input(files=["a.txt", "b.txt"])` iterates over lines from multiple files. `fileinput.filename()` gives the current file name. Useful for processing multiple input files like shell tools.

User: How do you use `typing.Protocol` for callback signatures?
Joe: Define a protocol matching the expected callable: `class Handler(Protocol): def __call__(self, event: Event) -> None: ...`. This is more explicit than `Callable[[Event], None]` when adding attributes.

User: What is `decimal.localcontext`?
Joe: `with localcontext() as ctx: ctx.prec = 50; result = Decimal(1) / Decimal(3)` temporarily sets precision for decimal calculations. The context is restored when the block exits.

User: How do you use `enum.unique`?
Joe: `@unique class Color(Enum): RED = 1; GREEN = 2` raises `ValueError` if any values are duplicated. It catches copy-paste errors in enum definitions.

User: What is `typing.Unpack`?
Joe: `Unpack[TypedDict]` lets you type-annotate `**kwargs` with a TypedDict. It provides precise keyword argument types when the function accepts a variable set of named parameters.

User: How do you use `dataclasses.field` with `compare=False`?
Joe: `field(compare=False)` excludes a field from `__eq__` and `__lt__` comparisons. Useful for fields like timestamps that shouldn't affect equality semantics.

User: What is `__format__` method?
Joe: `__format__(self, format_spec)` is called by `format(obj, spec)`. A class can define custom formatting: `format(price, ".2f")` delegates to `price.__format__(".2f")`.

User: What is `hashlib.pbkdf2_hmac`?
Joe: `hashlib.pbkdf2_hmac("sha256", password, salt, iterations=100000)` derives a key from a password using PBKDF2. Always use this or `bcrypt` instead of plain hashing for passwords.

User: How do you use `typing.Concatenate`?
Joe: `Concatenate[ParamSpec, str]` adds parameters to the front of a ParamSpec. Useful for typing decorators that add parameters: `def with_db(f: Callable[P, T]) -> Callable[Concatenate[DB, P], T]`.

User: What is the difference between `Mapping` and `MutableMapping`?
Joe: `MutableMapping` adds `__setitem__`, `__delitem__`, `pop`, `popitem`, `clear`, `update`, `setdefault` to the `Mapping` interface. Use `MutableMapping` for dictionaries you can modify.

User: How do you use `abc.ABCMeta`?
Joe: `ABCMeta` is the metaclass for `ABC`. `isinstance(obj, ABCMeta)` checks if a class uses it. You can combine it with other metaclasses: `class Meta(ABCMeta, OtherMeta)`.

User: What is `contextlib.ContextDecorator`?
Joe: A mixin that makes a context manager also work as a decorator. Implement `__enter__` and `__exit__` as normal, and the instance can be used with both `with` and `@` syntax.

User: What is `typing.NamedTuple` with defaults?
Joe: `class Point(NamedTuple): x: int; y: int = 0` gives `y` a default value. Fields with defaults must come after fields without defaults, just like function parameters.

User: How do you use `__contains__` for custom membership testing?
Joe: Define `def __contains__(self, item): return item in self._data` to customize `in` operator behavior. For example, a `Range` class could efficiently check if a number is within bounds.

User: How do you use `os.path.relpath`?
Joe: `os.path.relpath("/a/b/c.txt", "/a")` returns `"b/c.txt"`. It computes the relative path from a start directory to a target path, useful for display or portable references.

User: What is `struct.pack_into`?
Joe: `struct.pack_into("ii", buffer, offset, a, b)` packs data directly into a pre-allocated buffer at a given offset. More memory-efficient than `pack` when building large binary messages.

User: How do you use `io.BufferedReader` and `io.BufferedWriter`?
Joe: `BufferedReader(raw_file)` reads data in chunks for efficiency. `BufferedWriter(raw_file)` buffers writes. Both reduce system calls. The built-in `open()` uses buffering by default.

User: How do you create a dynamic property?
Joe: Use `@property` with a custom `__getattr__`. Or use descriptors: define a class with `__get__` and assign it to a class attribute. Both approaches allow computed attributes.

User: What is `abc.abstractproperty`?
Joe: `abstractproperty` is deprecated. Use `@property` combined with `@abstractmethod` instead: `@property @abstractmethod def value(self): ...`. This enforces that subclasses implement the property.

User: How do you use `inspect.signature`?
Joe: `sig = inspect.signature(my_func); sig.parameters` gives an OrderedDict of Parameter objects. Each parameter has `name`, `annotation`, `default`, and `kind` (POSITIONAL_OR_KEYWORD, etc.).

User: What is `typing.get_origin` and `typing.get_args`?
Joe: `get_origin(list[int])` returns `list`. `get_args(list[int])` returns `(int,)`. Useful for introspecting generic types at runtime to build adapters or serializers.

User: How do you use `pathlib.Path.mkdir` with parents?
Joe: `Path("a/b/c").mkdir(parents=True, exist_ok=True)` creates all intermediate directories. `parents=True` is like `mkdir -p`. `exist_ok=True` prevents errors if the directory already exists.

User: How do you use `dataclasses.KW_ONLY`?
Joe: Fields after `KW_ONLY` must be passed as keyword arguments. `@dataclass class User: name: str; KW_ONLY; age: int` means `User("Alice", age=30)` requires `age` as keyword.

User: How do you use `typing.assert_type`?
Joe: `assert_type(value, int)` tells the type checker that `value` must be `int`. If the checker disagrees, it raises an error. It's purely for static analysis and has no runtime effect.

User: What is `typing.assert_never`?
Joe: `assert_never(value)` is used after exhaustive type checking. If the type checker can prove the code is reachable, it flags an error. It ensures all enum cases or union branches are handled.

User: How do you use `functools.reduce` with an initial value?
Joe: `reduce(lambda a, b: a + b, [1,2,3], 0)` starts with initial value 0. Without an initial value, the first element is used as the accumulator start, and the iterable must not be empty.

User: What is `__delattr__` used for?
Joe: `__delattr__(self, name)` is called when `del obj.name` executes. Override it to prevent deletion of attributes or to implement custom deletion behavior, like removing from a database.

User: How do you use `typing.TypeAlias` with forward references?
Joe: `MyType: TypeAlias = "SomeClass"` allows forward references in type aliases. The string is lazily evaluated when the type hint is accessed, resolving circular import issues.

User: How do you use `collections.abc.Sequence`?
Joe: `Sequence` defines `__getitem__`, `__len__`, `index`, and `count`. It's the type for read-only list-like objects. `MutableSequence` adds `__setitem__`, `__delitem__`, `append`, `insert`, etc.

User: What is `dataclasses.replace`?
Joe: `replace(instance, x=5)` creates a new dataclass instance with some fields changed. It's useful for modifying frozen dataclasses since direct assignment raises an error.

User: How do you use `importlib.resources`?
Joe: `importlib.resources.files("package").joinpath("data.txt").read_text()` accesses package data files. It works correctly with zipped packages and is the recommended way to read package resources.

User: What is `pathlib.PurePosixPath` and `PureWindowsPath`?
Joe: `PurePosixPath("a/b")` uses forward slashes. `PureWindowsPath("a\\b")` uses backslashes. They let you construct paths for a target OS regardless of your current platform.

User: How do you use `collections.deque` with maxlen?
Joe: `deque(maxlen=1000)` automatically discards items from the opposite end when full. Perfect for sliding windows or recent-history buffers: `buf.append(item)` evicts the oldest when full.

User: How do you use `typing.TypeVar` with bounds?
Joe: `T = TypeVar('T', bound=Number)` restricts `T` to `Number` or its subclasses. `T = TypeVar('T', int, str)` restricts `T` to exactly `int` or `str`. Both are for constrained generics.

User: What is `dataclasses.field` with `repr=False`?
Joe: `field(repr=False)` excludes a field from the auto-generated `__repr__`. Useful for sensitive data like passwords or fields with circular references that can't be safely displayed.

User: How do you use `collections.abc.Callable` for type hints?
Joe: `Callable[[int, str], bool]` from `collections.abc` is preferred over `typing.Callable` for Python 3.9+. It has the same syntax but doesn't require importing from the `typing` module.

User: What is `typing.Self`?
Joe: `Self` (Python 3.11+) represents the type of the current class. `def copy(self) -> Self:` means the method returns the same type as the instance. Useful for method chaining in subclasses.

User: How do you use `pathlib.Path.suffix` and `suffixes`?
